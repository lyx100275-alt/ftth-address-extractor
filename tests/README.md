# tests —— 回归语料与校验方法

本目录存放**回归测试入口**（`run_smoke.py`）与校验规范。
语料 DXF 自 0.109.0 起**外置到版本库**（`技能版本库/ftth-address-extractor/tests/corpus/`），技能目录不再携带语料，避免体积膨胀。语料文件名为通用代号（`test_a.dxf` / `test_b.dxf` / `test_c.dxf`），不含任何真实项目名、企业名、人名、联系方式。

## T5 点亮（2026-09-26 已验证通过）

```bash
# 本机版本库语料位置（TeleAgent 工作空间）：
#   <工作空间>/技能版本库/ftth-address-extractor/tests/corpus/test_a.dxf
python tests/run_smoke.py --with-dxf --corpus "<版本库>/ftth-address-extractor/tests/corpus/test_a.dxf"
# 或设环境变量 FTTH_TEST_DXF 再跑（等效，CI 推荐，避免命令行写绝对路径）
```

> 注意：上例目录名以本机实际 `技能版本库` 为准，换机先 `dir` 确认；
> 三处解析顺序为 `--corpus` > `FTTH_TEST_DXF` > 技能内置路径，三者皆无则 T5 自动 SKIP（不阻断）。
> CI 如需缺料即失败：置 `FTTH_REQUIRE_CORPUS=1` 后跑冒烟，T5/T14 的缺料 SKIP 转 FAIL；结尾另打印 SKIP 清单。


## 脱敏规则（通用原则）

1. **只脱可定位到真实项目 / 企业 / 人的标识**；业务数据（楼栋 / 单元 / 层 / 户号 /
   FX 编号 / 光缆规格 / 几何坐标 / 排版参数）**一概不脱** —— 脱了语料就失去测量价值。
2. **词边界保护**：替换前必须校验命中处是否落在合法词边界上，否则会误伤非目标数据。
   已实测的失效案例：把 `1[3-9]\d{9}` 当手机号，命中浮点数值
   `0.49411764705882355` 中的 `17647058823`，**篡改图形数据**。故：
   - 中文串（项目名 / 企业名 / 人名）→ 命中处前后不得紧邻中文字符；
   - 数字串（电话等）→ 命中处前后不得是数字或小数点；
   - 仅自身足够特异的串（邮箱）可裸替换。
3. **长串优先**：规则按原串长度降序执行（`林荫书院项目` 先于 `林荫书院`）。
4. 不要求等长：DXF 是「组码行 / 值行」交替的文本格式，字节替换不改变组码结构，
   结构完整性由下述校验独立证明。

逐条替换明细见 `corpus/*.manifest.json`。

## 如何校验语料（三层，缺一不可）

**只比解析产物是不够的。** 上面的浮点误伤案例**不会**出现在任何文字值列表里 ——
只对拍 probe 产物会给出假的绿灯。必须做全量字节级校验：

1. **结构对拍**（证明只改了字面量，没动任何 DXF 结构）
   DXF 组码行 / 值行严格交替，故：
   - 行数必须相同；
   - 所有组码行（偶数索引）必须逐行完全一致；
   - 差异只允许出现在值行，且差异行数应等于替换处数。

2. **差异审计**（证明没有误伤）
   逐处定位每个替换命中，用词边界判据判定其是否合法；真误伤必须为 0。

3. **真机 probe 对拍**（证明语料仍可被技能正常解析，且测量结果不变）
   ```bash
   # 原图与脱敏图各跑一次，比对产物
   <python-with-ezdxf> scripts/ftth.py probe --dxf <corpus.dxf> --out <out.json>
   ```
   通过判据：两次均 rc=0；产物**键集合差异为 0**；
   同键值差异**只出现在被替换的字面量上**。
