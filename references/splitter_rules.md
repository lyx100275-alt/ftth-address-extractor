# 分光方式：线索呈现规则

> **规则**：分光方式若DXF图上未直接写明，**禁止自行推断**，只能将图纸已知事实和芯数关系作为线索列出，交用户裁决。

## 一、DXF可直接读出的信息（直读，可写入结果）

以下信息若DXF图上有文字标注，直接提取：

- 光缆型号（如GYSTA-XXD）
- 每箱熔接芯数（如"熔N芯"）
- 箱体容量（如"N芯箱"）
- 光交规格（如"NNN光交*N台"）
- 显式分光比标注（如"1:32""PLC 1:8""分光器1:4"）——若有则直接读取，标注"直读"

## 二、DXF通常无法直接读出的信息（待确认，禁止推断）

分光方式（一级分光 vs 二级分光）在大多数FTTH楼层图纸中**无显式文字标注**。

当DXF未写明分光方式时，助手**不得自行判断**，必须将以下线索整理后提交用户：

### 线索清单格式

| 字段 | 内容 |
|------|------|
| **问题** | 本项目采用一级分光还是二级分光？ |
| **图纸已知事实** | [从DXF直读：光缆型号、每箱熔接芯数=进线芯数、箱体容量、单箱覆盖户数] |
| **参考线索** | [仅供用户参考：一级分光需进线芯数≥覆盖户数；二级分光需一级比×二级比=箱体容量。用实际直读数值代入检查可行性] |
| **需要您裁决的内容** | 请确认分光方式（一级/二级），以便在地址表中正确标注分光器关联关系 |

### 注意事项

- "参考线索"中的芯数推算**仅供用户参考**，助手不得将其作为结论写入地址表
- 即使芯数关系"明显"指向某种分光方式，也不能自行下结论
- 线索中的数值全部来自DXF直读，推算逻辑仅是提示用户"可能是什么"的理由，不是结论
