## 模板规则

标准地址模板已存放在 `assets/标准地址表模板.xlsx`，Sheet名"标准地址"，24列（A~X），1行表头+1行示例数据，无合并单元格。助手在生成成品时：

- **模板路径**：`assets/标准地址表模板.xlsx`（随skill分发，跨机可用）
- **格式严格跟模板**：列结构、列顺序、表头名称、地址写法、户号格式、分纤箱编号列位置、合并单元格方式、表头行数等，全部以模板为准。**表头须原样照抄** —— 模板表头尾部的 `(必填)` 是模板内容的一部分，**不得清洗或规整**：内部字段映射用的归一化不得作用于输出表头（实测某轮：二者复用一个函数，产物 5 个列名被悄悄改写、生成侧无告警，直到对产物回读才暴露）。出表后由出口断言拿**模板原文**逐列比对。
- **分纤箱列（P 列）格式：编号＋（安装楼层）**（2026-09-28 用户裁决）：每个分纤箱编号后加**全角括号**，内填该箱**安装楼层原值**（解析阶段判定值，如 `FX01#（5F）`；`-1F`/`B1` 等写法与图纸/解析口径一致、不做归一化）。来源与纪律：coverage JSON 优先、parse JSON 回退；双来源都有且不一致＝矛盾即停（L0-I4，gen rc=2）；均缺失＝不编造，该箱保持纯编号并告警（列待确认）；空值/「未分配」不加括号。开关：`gen_addressbook.py --fx-floor-suffix on`（默认）/`off`（回退纯编号）。
- **数据全部从DXF独立生成**：模板中的示例数据行仅用于展示格式，实际输出时替换为从DXF提取的真实数据，不得照搬模板中的任何数据

## 回读校验与 AIGC 水印行（2026-09-25 立）

- **生成时校验口径**：`gen_addressbook.py` 生成即刻回读，行数恒等式为 `1 表头 + N 户数据 + 1 模板水印行`（模板第 3 行自带 AIGC 水印，随表头结构保留）。此时 max_row = N+2。
- **交付后行数可能增加，不是数据错误**：宿主对 `.xlsx` 产物会**自动追加 AIGC 水印行**（实测凤鸣朝阳：生成时 315 行，复制到桌面后 317 行 —— 宿主在第 316 空行后追加了第 317 行水印）。这是系统预期行为，不得据"行数 ≠ 恒等式"误判产物被篡改或解析丢户。
- **人工核对口径**：以「数据行数 = 源户数 N、表头 1 行」为准；水印行特征为第 1 列以 `AIGC:` 开头或整行仅首列非空。回读脚本统计户数时按 `楼栋列非空` 过滤即可天然排除水印行。
- **无模板11列回退（2026-09-27三轮）**：`gen_addressbook.py`未传`--template`时用内置11列出表（与24列模板不等价，属降级形态；触发时打显式警告）。九级树恒等式计数据行（`2+楼栋+单元+层+户`），扁平恒等式计`1表头+N数据+尾行`，两形态口径不同不得互套。
