# SKILL_CHANGELOG 归档（2026-10-02 一百四十五起启用）

本目录存 `SKILL_CHANGELOG.md` 的**历史**条目，按每 40 条一份切分。

**为什么归档**：全量 151 条曾挤在单文件（459 KB）。实测反查「`scripts/ftth.py`
最近何时改」只能匹配到 12 个修订之前 —— 中间变更无法定位；编辑器里打开也是负担。

**规则**
1. 新条目仍加在 `SKILL_CHANGELOG.md` **顶部**（说明段之后、最新条目之前）。
2. 主文件条目数超过 60 时，把**最旧的**整段移入本目录 —— 移动时不改一个字
   （`### ` 标题与正文原样保留），只换文件。
3. **中文序号是追溯的唯一依据**（`version.json` 的 minor 位即序号）。跨文件检索
   按序号，**不要按日期** —— 日期只写在标题里，跨月同序号会歧义。
4. 本目录内条目按**从旧到新**顺序排列（part01 最早，partNN 最新）。
